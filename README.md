# GuessTheFlag

A simple and fun flag guessing game built with SwiftUI for iOS.

## Features

- **Flag Quiz**: Displays a country's flag and prompts the player to pick the correct country from 4 options.
- **Round-based Gameplay**: 5 rounds per game with active round tracking.
- **Score Tracking**: Tracks your current score throughout the game.
- **Game Over Alert**: Displays final score and allows restarting the game.
- **Modern UI**: Styled with SwiftUI radial gradients and modern glass prominent buttons.

## Requirements

- iOS 17.0+
- Xcode 16.0+
- Swift 5.9+

## Getting Started

1. Open `GuessTheFlag.xcodeproj` in Xcode.
2. Select your target simulator or device.
3. Press **Cmd + R** or click the **Run** button to build and run the application.
## How to Play

1. Observe the country flag displayed on screen.
2. Tap the button corresponding to the correct country name.
3. Your score increases by 1 point for every correct answer.
4. After 5 rounds, an alert displays your final score and offers an option to restart the game.
